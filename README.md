# DiceDrum — releases

Installers for **DiceDrum**, the dice-rolling MIDI drum groove generator by DiceAudio (VST3 + standalone app).
DiceDrum checks this repository once a day for a newer version (Settings → Check for updates) and installs it from here.

Download the latest version: [Releases](https://github.com/cootiewar/DiceDrum-Updates/releases/latest)

* `DiceDrum-<version>-Windows-Setup.exe` — the installer: VST3 into `C:\Program Files\Common Files\VST3`, the app into Program Files.
* `DiceDrum-<version>-VST3-Windows-x64.zip` / `DiceDrum-<version>-Standalone-Windows-x64.exe` — the same without installing.
* `latest.json` — read by DiceDrum's update check.
